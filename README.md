# 劇情排版圖片 — GitHub Pages 版

作者：懧雃  
僅供懧雃自娛自樂用

## 上傳到 GitHub

1. 解壓縮這個 ZIP。
2. 建立 GitHub 儲存庫，將解壓後的 `index.html`、`app.js`、`style.css`、`apple-touch-icon.png`、`.nojekyll` 和 `README.md` 上傳到儲存庫根目錄。請上傳解壓後的檔案，不要只上傳 ZIP 本身，也不要把整個資料夾包在儲存庫下一層。
3. 在儲存庫的 **Settings → Pages**，將 **Build and deployment → Source** 設為 **Deploy from a branch**，選擇檔案所在分支及 **/(root)**，然後儲存。
4. 發布完成後，到 Pages 設定頁開啟網站網址。

此網站是純靜態檔案，不需安裝套件或設定伺服器。故事、分段、設定及浮水印的暫存資料保存在使用者裝置的瀏覽器中；GitHub Pages 會使用新的網址，因此原網站的暫存內容不會自動轉移過來。

## 更新紀錄（2026-11）

- 貼上文字後預覽會自動產生、自動更新
- 新增常用尺寸（4:5、3:4、9:16、1:1）、行距、段落首行縮排、配色主題
- 「每張圖卡都使用設定的高度」：所有圖卡尺寸一致（可關閉，恢復依內容調整高度）
- 中文避頭尾：逗號、句號等標點不會出現在行首，開括號不會留在行尾
- `\*` 可顯示星號本身；顯示字數與段數
- 清除暫存前會先確認；修正浮水印調整時可能中斷預覽更新、翻頁時預覽捲動位置不準的問題
- 支援 iPhone「加入主畫面」圖示；更新檔案版本號，避免瀏覽器沿用舊快取
